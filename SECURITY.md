# Security Policy

The runtime images, the universal wrapper and hf-serve are part of RunR. They follow
[RunR's security policy](https://github.com/BRF-Tech/runr/blob/main/SECURITY.md): its supported
versions, how to report a vulnerability and what to expect.

In short: report vulnerabilities privately by e-mail to **security@runr.sh**. Do not open a public
issue, pull request or discussion for a suspected vulnerability. Name the image and tag (for
example `ghcr.io/brf-tech/runr/exec-python:3.12`) or the commit of this repository.
